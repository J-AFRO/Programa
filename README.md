# v.pradinė
Ši versija programos versija įpareigoja vartotoją ranka įvesti visus duomenis (Vardus, pavardes, pažymius).
Yra padaryta apsauga kuri blokuoja blogai ar neteisigai suvestus duomenis.
Ši versija yra pati pirma, jos efektyvumas nėra geras, nes yra ribotas kiekis duomenų kuriuos galima pateikti. Norint pateikti daugiau duomenų, reikia rankiniu būdu redaguoti 19 kodo eilutę "main.cpp" faile.
